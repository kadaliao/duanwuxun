# 端午汛

《大明王朝1566》同人 2.5D 游戏。嘉靖四十年五月，你是户部观政进士程知白，到浙江淳安核田。三天之后是端午，那一夜，新安江的大堤会决。

等距视角的 3D 世界（Three.js），像素人物，昼夜与雨，实时的洪水。

## 怎么玩

```
npm install
npm run build        # 打包到 build/game.js
npm run dev          # http://127.0.0.1:8567
```

浏览器打开 `http://127.0.0.1:8567/`（需要 http 服务，直接双击 index.html 不行：字体和图片要走 fetch）。

- WASD / 方向键 走，Shift 跑，C 潜行，空格 / 鼠标点人 互动，Q / E 转视角，滚轮缩放。
- J 账簿（线索、暗账、随身、人物），Esc 卷宗（存读档、设置）。
- 对话里字下带红点的词可以点开"听音"，听话里的话，记进账簿。
- 手机：左下摇杆、右下按钮。

## 结构

- **三天白天**：淳安城、大堤、闸口、冯家村、渡口、后山龙王庙之间自由走动。和人说话、听堤、查河工账、帮村民——攒下村民的信任、线索与人情。夜里戌时以后，闸口会有号衣兵来撬闸底的石头，可以潜行过去听。
- **第三夜推算**：把线索摆开，写下一个日子。线索够、写对了，就能在端午前夜挨家挨户敲门。
- **端午夜**（实时）：子时决堤。在那之前，要锣、要民壮、借船、看清闸口的人、把村里的人带上山。决堤之后水从闸口漫开，田、路、村子依次淹没；没走的人困在屋顶上，要撑船去救；阿秧回去拿田契，在冯家的屋脊上；决口边有一块按察使司的腰牌。丑时胡宗宪上堤分洪。
- **结账**：活民、阿秧、吴老倌、证据、呈文、分洪时说了什么……八种结局标题。

大势改不了：堤一定会决，严党一定会倒。你能改的，是多少人活下来，和你自己最后成了什么样的人。

## 开发

| 命令 | 作用 |
|---|---|
| `npm run watch` | esbuild 监听 |
| `node tools/playtest.mjs full` | 自动试玩全流程并截图到 `tools/shots/play/`（`PREFER=best/random/first` 选择分支偏好；`night` 只跑端午夜） |
| `node tools/shot.mjs out.png "js"` | 跑一段脚本后截图 |
| `node tools/subset-font.mjs` | 改了文本后重新裁剪楷体字库 |
| `node tools/gen-batch.mjs` | 按 `art/manifest.json` 生成绣像（codex image_gen）；`tools/process-art.sh` 转 webp 并去底 |

代码：`src/engine/`（渲染、地形、建筑、人物精灵、寻路、天气、音频——全部程序化，没有外部模型与音频文件），`src/game/`（地图、导演、界面、状态），`src/game/script/`（剧本：序章、三天、端午夜、结局、线索、小游戏、潜行）。
